# coinsnap-collector

AI-powered coin collection and valuation app for coin identification, rarity detection, and market research.

## Security

Provider API keys must remain server-side. The browser calls a configurable AI proxy (`VITE_AI_PROXY_URL`, default `/api/ai/identify-coin`) and must never receive a Gemini/OpenAI/provider credential.

## Status

Complete as an experimental numismatics and collectibles project.
